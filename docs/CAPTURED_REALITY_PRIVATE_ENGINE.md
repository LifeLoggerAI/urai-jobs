# Private reconstruction engine and media redemption

Source-only implementation for Jobs #151. No service has been deployed, CUDA training run, private media transferred, compute purchased, or reconstructed world admitted by this change.

The existing `memory.private-source.reconstruct-place` worker still owns dispatch and callback authority. It now checks stored owner identity, exact lease, both `memory.storage` and `location.context` consent contexts, and canonical revocation blocks before requesting handles and atomically before dispatch. A stale callback lease cannot finish a newer job attempt.

`workers/captured-reality-worker/reconstruction-engine.js` implements the worker's `/reconstruct` contract. It requires bearer authentication, a fixed callback origin with the worker's callback token, exact engine SHA/revision, exact Spatial SHA/component envelope, opaque accepted inputs, a private output mount, and an explicitly enabled bounded compute authority. Missing CUDA, Torch CUDA support or Nerfstudio binaries makes readiness fail. No install/deploy/provision script creates compute or enables training.

The only implemented method is baseline `3dgs`. Other advertised reconstruction methods are rejected rather than routed to an approximate success. An authorized frame-set runs:

1. `ns-process-data images --data 04_frames_accepted --output-dir 05_colmap_processed`
2. `ns-train splatfacto --data 05_colmap_processed --output-dir 06_training --max-num-iterations <bounded ceiling> --vis tensorboard`
3. `ns-export gaussian-splat --load-config <one generated config> --output-dir 07_archival`

The command plan is server-owned, uses argument arrays without a shell, and admits no caller-authored command or training parameters. There is one active compute job, at most 3,000 accepted frames, 256 MiB per frame, 2 GiB aggregate inputs, 30,000 iterations, 45 minutes total and 2,000,000 exported Gaussian records. Command output is retained only in a bounded private temporary log. Source authorization is checked between stages and polled during computation; cancellation/revocation terminates the whole subprocess group.

The engine verifies source bytes before camera solving. It packages the actual exported binary little-endian Gaussian PLY into the browser's 32-byte splat layout. A separately hashed GLB conservatively blocks the complete measured visual envelope. It deliberately reports `navigationAccepted:false` and `metricScaleVerified:false`; it is not an accepted interior, metric reconstruction or navmesh. Camera, training and source-comparison receipts retain current source/config/binary hashes, lineage and timings. The comparison receipt is explicitly unreviewed and grants no identity, literal quality, device, XR, art or release acceptance.

`private-media-resolver.js` provides bearer-authenticated `/resolve`, `/redeem` and `/check`. It reads a protected, owner-populated manifest and a private source mount. It returns bytes or opaque bounded descriptors; filesystem paths and owner IDs never leave its responses. The resolver rejects world-readable grants, expired grants, unaccepted inputs, hash/size mismatches, traversal and symlinks. Authority is either the protected source authority's authenticated `validate-reconstruction-handles` endpoint or the implemented canonical Jobs Firestore adapter. The Firestore adapter consumes current stored job/source receipts, owner, callback lease/deadline, exact callback-token hash and existing consent blocks. Accepted attempt hashes permit post-success delivery; a changed lease/token cannot keep an older engine authorized. It creates no second consent registry.

A private grant contains `entries`, each with `jobId`, `sourceHandle`, server-owned `ownerUid`, `sourceReceiptRef`, `expiresAt` and `acceptedInputs`. Each accepted frame has `inputRef`, `frameProvenanceRef`, private relative `path`, `sha256`, `byteSize`, `mimeType` (`image/png` or `image/jpeg`) and `accepted:true`. The protected ingestion owner must derive these records from authorized fixity/frame review. Original videos, rejected frames and unknown frame provenance are not silently sampled or admitted by this engine. Do not commit a real grant, source bytes, private source paths, names or transcripts.

Private artifacts live on the configured persistent mount behind opaque `cr-artifact:<job digest>:<byte digest>` references. `/artifact` requires service authentication and a fresh source authorization check. `/cancel` aborts active computation. `/delete` requires actual subprocess cleanup before acknowledging removal, scrubs callback/source state and retains only an idempotency tombstone. Jobs consent revocation and governed data-rights deletion invoke this endpoint and retain a pending state if it does not acknowledge deletion. The data-rights executor cancels all in-flight owned attempts before record deletion, removes both output aliases and permits at most three exact-identity attempts after explicit retryable failure; an active attempt or a completed replay cannot execute again. A missing engine token/endpoint is a fail-closed privacy blocker when an engine may hold derivatives.

Retries cannot silently retrain. An ambiguous success callback remains `CALLBACK_PENDING` with private outputs; `/retry-callback` retries delivery of the same hashes. Restart recovery removes abandoned source/output workspaces and records failure instead of rerunning paid training. Run the engine under a supervisor/container that terminates its whole cgroup on process loss; a parent process alone cannot clean a SIGKILL orphan. A governed new attempt is required after interruption. No opaque artifact ref by itself proves that Storage/browser delivery, export inclusion, central deletion or deployment is accepted.

Start source services explicitly with `npm run start:engine` or `npm run start:resolver` from the worker directory. The normal worker command and default production deployment set are unchanged. The stock Node worker image has no CUDA/Nerfstudio training authority and will fail engine readiness. An independently authorized runtime must supply those binaries; this change does not create it.

Required protected bindings are listed in `ops/production.env.example`. The engine token must be supplied by managed secret injection both to the engine and to the Jobs privacy/data-rights executor; never place a token in a URL, repository or public evidence. Bind the resolver to the canonical Jobs Firebase project and provide least-privilege ADC for job/consent reads. TLS and private ingress are required outside local tests. The state/artifact mount must be private and persistent; ephemeral frame workspaces must remain reproducibly disposable.

Validation uses real HTTP/file/storage control paths with synthetic fixtures and injected command/runtime doubles. These tests are source evidence only. Real private accepted frames, actual CUDA readiness/training, deployed-worker callback/restart/revocation/deletion, artifact delivery, metric geometry/navigation, literal reconstruction/source comparison, physical devices and independent exact-head review remain distinct gates.

Primary command references: [Nerfstudio Splatfacto](https://docs.nerf.studio/nerfology/methods/splat.html), [Nerfstudio training visualizers](https://docs.nerf.studio/quickstart/first_nerf.html), [Nerfstudio CLI](https://docs.nerf.studio/reference/cli/index.html).
